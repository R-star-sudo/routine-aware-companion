# routine-aware-companion

An assistive system in planning for elderly people that will learn individual
daily routines and provide proactive reminders and caregiver alerts.

## Project status

This repository currently contains the initial project structure and design
guidelines only. The application, device firmware, database integration, and
predictive services have not been implemented. No dependencies are installed,
and there are currently no setup or run commands.

See [docs/architecture.md](docs/architecture.md) for the planned component
boundaries and implementation status.
